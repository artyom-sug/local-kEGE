# kompege tracker
kompege tracker - это расширение для kompege.ru. С ним вы сможете отслеживать прогресс своей подготовки к ЕГЭ по информатике.
Для тестирования, доработки и использования (если расширение не загружено в магазин расширений Chrome) воспользуйтесь следующей инструкцией:
1) Скачайте копию репозитория на своё устройство: Code -> Download ZIP или через git clone
2) Перейдите в браузере по ссылке browser://extensions/
3) Включите режим разработчика, если он выклюен
4) Нажмите "Загрузить упакованное расширение" и выберите папку проекта
5) Включите расширение и готовьтесь к ЕГЭ с комфортом!
